# Algoritmos em C++

Coleção de implementações para estudo de **ordenação, busca, recursão e matemática computacional**.

**Linguagem:** C++  
**Status:** Exercícios de lógica e algoritmos.

## Algoritmos incluídos

| Categoria | Implementação |
|---|---|
| Ordenação | Bubble Sort |
| Ordenação | Merge Sort |
| Ordenação | Quick Sort |
| Busca | Busca binária em sequência ordenada |
| Sequências | Fibonacci iterativo |
| Matemática | Crivo de Eratóstenes (números primos) |

O `main` contém exemplos que executam essas rotinas e exibem resultados no terminal.

## Executar
```bash
git clone https://github.com/fgscarvalho37-a11y/algorithms.git
cd algorithms
g++ -std=c++17 algorithms.cpp -o algorithms
./algorithms
```
